## 管理员操作手册

### 1. 登录管理后台

1. 访问 `https://your-domain.com/login`
2. 使用管理员账号登录
3. 登录后进入中文管理后台

### 2. 仪表盘概览

管理后台首页展示：
- 用户总数
- 问卷总数
- 已发布问卷数
- 总答卷数
- 近30天答卷趋势图
- 热门问卷排行

### 3. 用户管理 (仅超级管理员)

路径: **用户管理**

功能：
- 查看所有注册用户列表
- 按邮箱/姓名搜索用户
- 启用/禁用用户账号
- 删除用户（会同时删除该用户的所有问卷和答卷）
- 查看用户的角色（超级管理员/管理员/普通用户）

操作步骤：
1. 点击左侧菜单「用户管理」
2. 可使用搜索框查找特定用户
3. 点击启用/禁用按钮切换用户状态
4. 点击删除按钮移除用户（需确认）

### 4. 全站问卷管理 (仅超级管理员)

路径: **全站问卷**

功能：
- 查看所有用户发布的问卷
- 按标题或发布者搜索问卷
- 删除违规或不需要的问卷
- 查看问卷收集的答卷数量

### 5. 审核问卷

超级管理员可以：
- 查看所有问卷的发布状态
- 删除不符合规范的问卷
- 联系问卷发布者（通过用户名）

## 普通用户操作手册

### 1. 注册账号

1. 访问 `https://your-domain.com/register`
2. 填写邮箱、密码、姓名
3. 点击「注册」完成

### 2. 登录

1. 访问 `https://your-domain.com/login`
2. 输入邮箱和密码
3. 点击「登录」

### 3. 创建问卷

1. 登录后点击左侧菜单「问卷管理」
2. 点击右上角「创建问卷」
3. 填写问卷基本信息（英文）：
   - 问卷标题
   - 问卷描述
4. 添加题目：
   - 选择题型（单选/多选/文本）
   - 填写题目内容（英文）
   - 添加选项（选择题）
   - 设置是否必填
5. 点击「保存草稿」或「保存并发布」

### 4. 编辑问卷

1. 进入「问卷管理」页面
2. 找到要编辑的问卷
3. 点击编辑图标
4. 修改内容后保存

### 5. 发布/取消发布问卷

1. 在问卷列表中，点击编辑问卷
2. 点击「保存并发布」发布问卷
3. 已发布的问卷会显示绿色「已发布」标签

### 6. 获取二维码

1. 进入「问卷管理」页面
2. 找到已发布的问卷
3. 点击二维码图标
4. 页面切换到「二维码」标签
5. 可执行操作：
   - **下载二维码**: 点击「下载二维码」按钮保存PNG图片
   - **打印**: 点击「打印问卷」打印A4版问卷
   - **复制链接**: 复制问卷URL分享给受访者

### 7. 查看问卷数据

1. 进入「问卷管理」页面
2. 找到已发布的问卷
3. 点击二维码图标
4. 页面默认显示「数据分析」标签
5. 可以看到：
   - 每道题的选择分布柱状图
   - 饼图分析（选择题）
   - 数据表格

### 8. 导出数据

1. 在数据页面点击「导出CSV」
2. 浏览器下载CSV文件
3. 可用Excel打开进行进一步分析

### 9. 打印问卷PDF

1. 在二维码页面点击「打印问卷」
2. 打印设置中选择A4纸张
3. 打印即可获得带页眉页脚的正式问卷

## 受访者使用说明

### 1. 扫码答题

#### 支持的扫码方式：
- **Microsoft Edge / 微软手机浏览器**: 相机扫描
- **手机原生相机**: 直接扫码
- **WhatsApp**: 扫描二维码
- **Telegram**: 扫描二维码
- **Safari (iOS)**: 相机扫描
- **Chrome (Android/iOS)**: 相机扫描
- **其他扫码APP**: 微信、支付宝等

#### 答题步骤：
1. 用手机扫描问卷二维码
2. 浏览器打开问卷页面（英文）
3. 阅读导言，点击「Start Survey」
4. 逐页填写问卷题目
5. 完成后点击「Submit Survey」
6. 显示感谢页面，完成答题

### 2. 直接访问链接

1. 点击收到的问卷链接
2. 直接进入问卷页面
3. 按上述步骤完成答题

### 3. 知情告知书

受访者可以点击页面顶部的「Participant Information」查看：
- 研究目的
- 隐私保护说明
- 参与自愿性
- 伦理审查信息

### 4. 打印问卷

如需打印纸质版问卷：
1. 访问问卷页面
2. 按 `Ctrl+P` (Windows) 或 `Cmd+P` (Mac)
3. 选择A4纸张
4. 点击打印

## 常见问题

### Q: 二维码失效了怎么办？
A: 问卷修改后二维码不会失效，依然有效。如果需要新二维码，在二维码页面点击「重新生成」。

### Q: 能否修改已发布的问卷？
A: 可以，但修改不会影响已收集的答卷数据。

### Q: 如何删除已收集的答卷？
A: 目前只能删除整个问卷，答卷会一并删除。如需清空答卷数据，可以创建一个新的问卷。

### Q: 访客能否无需登录直接答题？
A: 可以，受访者通过二维码或链接直接访问，无需任何登录。

### Q: 问卷数据如何保密？
A: 只有问卷发布者和超级管理员可以查看数据。系统使用JWT认证确保安全。
