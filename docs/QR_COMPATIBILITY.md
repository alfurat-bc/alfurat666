# 扫码兼容说明

## 二维码技术标准

本系统使用的二维码遵循以下国际标准：

- **ISO/IEC 18004**: QR Code 国际标准
- **QR Code Version 2**: 中等密度，适合大多数扫描场景
- **容错率 M (15%)**: 即使二维码部分损坏也能正确识别
- **格式**: PNG 图像

---

## 微软扫码识别原理

### Microsoft Edge / 微软手机浏览器

Microsoft Edge 使用以下技术识别二维码：

1. **摄像头访问**: 通过 `navigator.mediaDevices.getUserMedia()` 访问设备摄像头
2. **实时预览**: 在页面中显示摄像头实时画面
3. **图像分析**: 使用 JavaScript QR 库实时扫描视频帧
4. **解码**: 识别二维码后提取 URL 信息
5. **跳转**: 自动打开浏览器导航到目标网页

### 为什么微软扫码能完美兼容？

- Edge 使用开源的 ZXing (Zebra Crossing) 算法库
- 该算法被全球绝大多数二维码扫描器采用
- 符合 ISO/IEC 18004 标准
- 支持所有主流 QR Code 格式

## 注意事项

### 1. HTTPS 必需

二维码包含 HTTPS URL，这是现代浏览器的安全要求：

- 浏览器只能在 HTTPS 页面访问摄像头
- 混合内容 (HTTP + HTTPS) 会导致扫码失败
- 本系统强制使用 HTTPS 加密连接

### 2. 二维码尺寸建议

打印时建议二维码尺寸：

| 用途 | 最小尺寸 | 推荐尺寸 |
|------|---------|---------|
| 手机屏幕显示 | 150×150 px | 200×200 px |
| A4 纸张打印 | 2×2 cm | 3×3 cm |
| 海报/展板 | 5×5 cm | 8×8 cm |

### 3. 打印质量

- 使用 300 DPI 以上打印质量
- 避免过度缩放导致扫码困难
- 确保二维码与背景有足够对比度
- 白色背景 + 黑色二维码效果最佳

## 故障排除

### 无法扫码？

1. **检查网络**: 设备需要联网才能打开问卷链接
2. **检查权限**: 确保浏览器有摄像头访问权限
3. **清理缓存**: 清除浏览器缓存后重试
4. **手动输入**: 如果扫码失败，可以直接复制链接到浏览器

### 扫码后打不开？

1. **检查链接**: 确保是完整的 HTTPS 链接
2. **服务器状态**: 联系管理员确认服务正常运行
3. **DNS 问题**: 尝试使用 IP 地址访问
